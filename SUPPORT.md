# Support

If you run into a bug or unexpected terminal behavior:

- Open an issue on GitHub:
  - `https://github.com/danbi2990/path-to-terminal/issues`
- Include the command you ran, if relevant
- Mention whether you triggered it from the editor, Explorer, or Open Editors
- Mention the expected output text and the actual output text

This helps reproduce path-formatting and terminal handoff issues more quickly.
